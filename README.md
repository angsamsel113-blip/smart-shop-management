# Smart Shop Management

A responsive web-based shop management application for managing products, inventory, sales, and reports.

## Features

- Product management
- Inventory and stock management
- Batch-wise expiry tracking
- Sales management
- Sales and stock reports
- Category management
- Low-stock and out-of-stock status
- Dark mode
- Responsive design
- Local Storage

## Technologies

- HTML5 
- CSS3
- JavaScript
- Local Storage
